## 下载

| 电脑 | 下载哪个 |
| --- | --- |
| Windows 10 / 11（64 位） | `AI盯播助手-版本号-安装包.exe` |
| Mac（Apple 芯片：M1、M2、M3……） | `AI盯播助手-版本号-macOS-arm64.dmg` |
| Mac（Intel 芯片） | `AI盯播助手-版本号-macOS-x64.dmg` |

不知道 Mac 是哪种芯片：点屏幕左上角的苹果图标 → 关于本机，“芯片”一栏写着 Apple M 开头的就是 Apple 芯片，写“处理器 Intel”的就是 Intel。

## 安装

**Windows**：双击安装包，按提示安装，不需要管理员权限。安装包没有数字签名，Windows 可能提示“Windows 已保护你的电脑”，点“更多信息”→“仍要运行”。

**Mac**：打开 dmg，把“AI盯播助手”拖进“应用程序”。程序没有经过苹果公证，第一次打开会提示“无法验证开发者”：打开“系统设置”→“隐私与安全性”，在下面找到“AI盯播助手”点“仍要打开”。Mac 版还不能采集电脑上播放的声音（“系统声音”），请用“直播间链接”“麦克风”或“音频文件”。

第一次使用要在程序里下载本地识别模型（约 240 MB），之后不用联网也能识别。场次记录、录音和设置保存在本机，卸载程序不会删掉它们。
